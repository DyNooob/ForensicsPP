Forensics++ ForensicsPP · Local-first digital forensics workbench

Browser-native DFIR tools that run on your device

Forensics++ is an open-source workbench for digital forensics and incident response. Evidence files are parsed locally in your browser and are never uploaded to a server.

No upload. Files stay on your device. Works offline once loaded.

Core workbenches

  • Windows Event Logs (EVTX)
  • SQLite Forensics
  • SQLite WAL Recovery
  • APK Signature Analysis
  • PCAP / Network Analysis
  • Registry Forensics
  • Firmware Analysis
  • Binary / Unknown File Analysis
  • Windows Artifacts
  • Image Forensics
