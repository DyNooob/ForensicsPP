# Forensics++ / ForensicsPP

This public copy summarizes the root project README for static hosting contexts.

Forensics++ Workbench is an open-source, browser-local DFIR workbench for evidence triage. The full source code is available at:

https://github.com/DyNooob/ForensicsPP

The source repository contains the React/Vite application source, build configuration, public assets, bundled workers, legal page, package lockfile, and documentation. Production output can be rebuilt from source.

## Build

```sh
git clone https://github.com/DyNooob/ForensicsPP.git
cd ForensicsPP
npm install
npm run dev
npm run build
npm run preview
```

The production build is generated in `dist/`.
