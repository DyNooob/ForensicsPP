## 修复与保留边界

修复：EXIF 信息不直观、缺少 HEIC 解码兜底、HEIF 数据结尾误判、离线查询依赖 CDN、离线收尾受 CDN 环境变量影响、离线时钟标为服务器时间、构建工具已知依赖告警。保留原有资源限制与初筛能力说明；没有将未验证的格式宣称为完全支持。

真实 HEIC 验证样本取自 exifr 项目公开测试夹具 `test/fixtures/heic-iphone.heic`（iPhone XS Max，4032×3024），只用于本地测试，不包含在发布 ZIP。归属地数据版本固定，不能替代实时定位或权属核查。手机号上游 LICENSE 为空的情况在随包来源说明中如实记录。

原始运行证据保存在项目 `tmp/` 的 release/offline 日志、截图和 JSON 报告。网页版本和离线版本使用不同的分发策略；本次 GitHub Release 将完整离线 ZIP、校验文件和验证记录作为正式附件发布。
