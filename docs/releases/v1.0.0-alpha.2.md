# Forensics++ v1.0.0-alpha.2

## 中文

这一版把“加入报告”做成了真正的证据登记动作。工具平时不会额外计算文件哈希；只有用户明确把当前结果加入报告时，系统才读取当前文件输入并登记来源信息。

### 主要更新

- 报告项记录源文件名、大小、类型、修改时间和 SHA-256。
- 报告预览增加证据清单，支持按文件核对来源、大小和哈希。
- Markdown、CSV、JSON 和 Bundle JSON 都包含源文件登记信息。
- Evidence Set SHA-256 将源文件登记信息纳入完整性摘要。
- 报告界面在桌面、平板和手机宽度下保持稳定，长哈希在清单区域内处理。

### 验证

- 74 项自动测试通过。
- 36 个工具在 1366 × 900 和 375 × 812 下通过布局审计。
- TypeScript、版权头、生产构建和 `dist/` 边界检查通过。

## English

This release turns “Add to Report” into an explicit evidence-registration action. The tools do not calculate another file digest during normal analysis. A source file is read and fingerprinted only after the user deliberately adds the current result to the report.

### Highlights

- Report items record source filename, size, type, modification time, and SHA-256.
- The report preview includes an evidence register for checking source, size, and digest per file.
- Markdown, CSV, JSON, and Bundle JSON exports include source-file records.
- The Evidence Set SHA-256 now covers the registered source-file metadata.
- The report remains stable across desktop, tablet, and mobile widths; long digests stay inside the register area.

### Verification

- 74 automated tests pass.
- All 36 tools pass layout audits at 1366 × 900 and 375 × 812.
- TypeScript, copyright headers, production build, and `dist/` boundary checks pass.
