# Forensics++ 1.0.0-rc.1

Candidate prepared: 2026-10-12 · Final validation: 2026-10-13 · 最后一个 1.0 前候选版本

This candidate repairs browser execution and release delivery while preserving the existing forensic workflows. It is a stabilization release, with no new parser claims.

本版聚焦现有工具的可运行性、状态一致性与离线分发，作为 1.0 前最后一个候选版本。

## Changes / 变更

- CyberChef updated to the latest official release, v11.5.0; deep-link embedding and new-window paths resolve from the app root. Missing embedded documents never fall back to the workbench shell. · 更新 CyberChef 至官方最新发布 v11.5.0，修复深链接内嵌及新窗口路径、离线误返回工作台的问题。
- Settings has clearer grouping, live appearance preview and mobile navigation. Static packs gain explicit localization with progress, cancellation and retry; the lookup Worker shares the same persistent cache. · 重整设置页和手机导航；静态数据包支持本地化、进度、取消和重试，查询复用本地缓存。
- Usage terms updated to 2026-10-13-v4, explaining stored state, downloaded packs, cleanup boundaries and embedded CyberChef network operations. · 更新使用条款、隐私及存储说明。

- Home recommends a target with a manual override. JWT/HTTP clues route directly; timestamps are distinguished from common identifiers, and ordinary navigation leaves existing tool inputs alone. Transient drafts stay in memory. · 首页支持建议与手动修正，普通导航不覆盖输入，转交草稿保留在内存。
- Lookup results page in groups of 100 with cross-page search and rule-status filters; CSV/JSON exports retain the entire batch. · 查询结果每页 100 条，支持跨页搜索和状态筛选，导出仍保留完整批次。
- All tools beyond Home have help. Regex no longer loads an unused IOC parser. URL, timestamp and regex tools gain practical samples; Home and sidebar use the same bilingual search and merged aliases. · 帮助与示例补齐，统一双语搜索。

- Hash workers import SM3 directly, avoiding SM2's Node-only initialization. The hash Worker shrinks from 116.8 kB to approximately 77 kB; other consumers also benefit. · 哈希 Worker 直接导入 SM3，避免 SM2 的 Node 初始化报错；该 Worker 从 116.8 kB 降至约 77 kB，其他引用方也同步减少代码。
- bcrypt uses a browser crypto shim with secure randomness and explicit failure when the random source is unavailable. · bcrypt 兼容浏览器，并在安全随机源缺失时明确报错。
- Every visible tool's generated URL survives direct navigation and refresh, including tools without a dedicated SEO slug. Legacy merged IDs still resolve to their workbench. · 所有工具生成地址均支持直接打开和刷新，历史合并别名仍可使用。
- JWT token, Header and Payload editors have accessible names. · JWT 三个编辑区补齐可访问名称。
- Lookup tasks terminate on Clear, input/type changes and tool switches. Language changes no longer kill a running query. Oversized batches require splitting rather than silent truncation. · 查询清空、修改输入/类型和切换工具时终止旧任务；切换语言保持任务；超限批次明确提示拆分。
- Service workers register at the application root and cache bootstrap JS/CSS during installation. Cache failures preserve successful network responses, and the build fingerprint covers the HTML shell. · 修复根目录 Service Worker 注册和启动资源缓存；缓存故障不会阻断在线资源；构建指纹包含 HTML 外壳。
- Clock checks time out and reject cached, slow or clock-jump samples. HTTP Date is described as a server-time estimate. · 时间检查增加超时，拒绝缓存、慢响应和本机时钟跳变样本；显示为服务器时间估计。
- Updated source-map-js and replaced the single-file build plugin to remove its vulnerable glob dependency chain. · 更新 source-map-js，替换单文件插件并移除存在告警的 glob 依赖链。

## Distribution / 分发

- `ForensicsPP-v1.0.0-rc.1-web-static.zip`: domain-root website deployment; configure SPA fallback to `index.html` for tool routes that do not have a generated static page. · 网站部署包，放在域名根目录；没有静态页的工具路径需要回退至 `index.html`。
- `ForensicsPP-v1.0.0-rc.1-standalone-static.zip`: main UI inlined; worker scripts and CyberChef remain separate. Double-clicking opens the shell/basic tools; full analysis needs HTTP. · 主界面内联分发包；Worker 和 CyberChef 为独立文件。双击可打开外壳和基础工具，完整分析需 HTTP。
- `SHA256SUMS-v1.0.0-rc.1.txt`: checksums for both candidate ZIPs. `SHA256SUMS.txt` keeps the cumulative record. · 本版两种发布包的校验值；通用校验文件保留历史记录。

For local full functionality, run `python3 -m http.server 8080` inside the unpacked standalone directory, then open `http://localhost:8080/`. No analysis backend is required. First-use lookup packs still need their fixed remote datasets; previously cached packs can be reused offline.

完整本地使用：在解压后的内联包目录执行 `python3 -m http.server 8080`，访问 `http://localhost:8080/`。不需要分析后端。归属地数据包首次使用仍需下载，已缓存的数据可离线复用。
