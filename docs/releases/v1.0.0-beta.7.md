# Forensics++ v1.0.0-beta.7

Release date: 2026-09-26

## 中文

本版本调整首页与全局框架，并加入浏览器端归属地查询。

### 归属地与规则核验

- 支持 IP、手机号、中国大陆身份证号和银行卡号的单条或批量输入。
- IP、手机号段和行政区划数据包按需下载，校验后写入 Cache Storage。
- 身份证号检查号码结构、出生日期、顺序码、校验位和行政区划代码。
- 银行卡号显示 BIN、卡组织和卡种，并执行长度与 Luhn 检查。
- 查询结果可复制为 JSON 或导出 CSV。
- 数据包写入浏览器缓存失败时，查询仍可继续，并报告缓存状态。

静态库结果用于辅助判断。IP 记录不代表设备实时位置；手机号携号转网后运营商信息可能变化；BIN 不代表开户支行或持卡人位置。

### 工作台

- 首页可输入文本或拖入文件，并自动选择对应工具。
- 首页输入会传递给 URL、哈希、时间戳、JSON、IOC 和归属地工具。
- Registry、Plist、浏览器数据和邮件文件可通过工具间交接直接打开。
- 顶栏显示服务器校准时间；点击后比较计算机时钟，偏差超过两秒时提醒。
- 图片工作台在载入图片后执行常见隐写、尾部数据、通道与修复检查。

### 界面与说明

- 设置默认打开“关于项目”，显示版本、构建 Hash 和相关站点链接，并提供源码仓库与条款入口。
- 移除重复的首次使用引导；更新法律说明中的本地存储与外部数据服务内容，并修复目录定位。

### 发布检查

- `npm audit --omit=dev`：0 个已知漏洞。
- 更新 `sm-crypto` 和 `pdfjs-dist` 到已修复版本，并更新相关传递依赖。
- 本次更新的完整校验结果以对应 GitHub Actions 记录为准。

## English

This release revises the home page and application shell, and adds browser-side attribution lookup.

### Attribution and validation

- Single and batch input for IP addresses, mobile numbers, mainland Chinese ID numbers, and bank-card numbers.
- IP, mobile-prefix, and administrative-division data packs are downloaded on demand, verified, and stored in Cache Storage.
- Chinese ID checks cover structure, birth date, sequence code, check digit, and administrative-division code.
- Bank-card results include BIN, card network, card type, length checks, and Luhn checks.
- Results can be copied as JSON or exported as CSV.

Static lookup results are supporting information. An IP record is not a device's live location; mobile carriers can change after number portability; a BIN does not identify a branch or cardholder location.

### Workbench

- The home page accepts text or a dropped file and selects the matching tool.
- Home-page input is passed to the URL, hash, timestamp, JSON, IOC, and attribution tools.
- Registry, Plist, browser-data, and email files can be opened through the in-memory tool handoff.
- The top bar displays a server-time estimate and compares it with the computer clock on request, warning when the difference exceeds two seconds.
- The image workbench runs common steganography, trailing-data, channel, and repair checks after an image is loaded.

### Interface and notice

- Settings now open on About, showing the version, build hash, related sites, source repository, and terms.
- The redundant first-run guide was removed. The legal notice now covers current local storage and external data services, and every contents link navigates to its section.

### Release checks

- `npm audit --omit=dev`: 0 known vulnerabilities.
- `sm-crypto`, `pdfjs-dist`, and affected transitive dependencies were updated to fixed versions.
- The complete verification result for this update is recorded in GitHub Actions.
