# Forensics++ v1.0.0 — 完整离线取证工作台

**正式版 · 2026-11-10 · 35 个工作台 · 简体中文 / English**

Forensics++ 1.0 将图片、文件、数据库、日志、邮件、网络与文本工具整合为浏览器工作台。本次正式版重点是可直接交付的完整离线包、更直观的图片元数据、HEIC/HEIF 本地预览，以及中文用户可离线使用的简繁转换。

## 下载与启动

| Release 附件 | 用途 |
| --- | --- |
| `ForensicsPP-v1.0.0-offline-static.zip` | **直接使用请下载这个**：完整应用、运行资源、查询数据、词库、启动器与版权材料 |
| `SHA256SUMS-v1.0.0.txt` | 发布 ZIP 的 SHA-256 校验值 |
| `ForensicsPP-v1.0.0-release-notes.md` | 本次发布说明的独立副本 |
| `ForensicsPP-v1.0.0-audit.md` | 工具体检、验证范围与限制 |

GitHub 自动生成的 “Source code” 是开发源码，不是可直接使用的离线应用包。

校验 ZIP 后**完整解压**，在解压目录执行：

```sh
python3 start_server.py
```

随后打开 `http://127.0.0.1:8765/`。Windows 可双击 `Start-ForensicsPP.bat`，macOS 可运行 `Start-ForensicsPP.command`。端口冲突时使用 `python3 start_server.py --port 8766`。

启动器使用**本机预装的 Python 3 标准库**，只监听回环地址，不执行 pip/npm 安装。Python 本身不随包分发；已有本地静态 HTTP 服务器也可使用。完整 Worker/WASM 分析需要 HTTP，不能只通过 `file://` 双击 HTML。

## 本次主要更新

### 图片：先看到提取结果，再深入结构

- 图片概览优先显示已提取的拍摄时间、设备、镜头、GPS、编辑软件和说明；没有内容的卡片不会占位。
- 完整 EXIF/元数据表直接展开，常用、有内容的字段排在前面；支持中文/原始字段名/内容搜索、空字段开关和继续加载。
- JSON 导出包含完整元数据，不受当前搜索或表格显示条数限制。
- 保留原始拍摄时间文本，避免把没有明确时区的 EXIF 时间擅自换算或标记成 UTC。
- HEIC/HEIF 在浏览器无法原生显示时使用随包解码器生成本地预览；支持 PNG 预览导出。元数据和容器分析始终读取原始文件，转换预览是独立衍生物。
- 修复 HEIF 容器边界判断：按 ISO BMFF box 读取完整结构，避免把正常 meta/mdat 数据误判为尾部附加内容；处理嵌套尺寸信息、扩展长度和截断边界。

### 中文：词组级离线简繁转换

入口：**编码解码 → 简繁转换**。

- 内置 OpenCC JS 和词库，支持繁体→简体、简体→繁体。
- 提供标准繁体、台湾字形、台湾地区词组、香港字形选项；地区用词与单纯字形转换明确区分。
- 支持 UTF-8 文本文件导入、复制、输入/结果交换和 TXT 下载。
- `Ctrl/⌘ + Enter` 转简体；`Ctrl/⌘ + Shift + Enter` 转繁体。
- 使用词组规则区分“头发 / 发展”等上下文；姓名、专有名词和一对多字形仍需复核。

### 分发：首次使用也能完整离线

- JS、CSS、WASM、Worker、CyberChef、OpenCC 词库和 IP/手机号段/行政区划数据全部随 ZIP 提供。
- 查询读取随包固定数据，不会因缺失本地数据而回退 CDN；无需首次联网下载或预热缓存。
- 离线构建和收尾脚本都忽略在线 CDN 环境变量，输入缺失或哈希不符直接失败。
- 每个离线 HTML 入口，包括独立打开的 CyberChef，都限制外部运行资源和连接。依赖外部服务的 CyberChef 操作在该版本中不可用。
- 增加从已下载离线 ZIP 导入重建材料的 `prepare:offline` 命令；导入和构建阶段不自动下载材料。
- 发行包附本地启动器、使用说明、版本清单、依赖许可证、数据来源、HEIC 对应源码和构建说明；ZIP 保留启动器可执行权限。

## 兼容性与已知边界

- 使用当前仍维护的浏览器；内存、文件大小、像素与解压预算继续适用。HEIC 特殊编码或损坏文件可能无法预览，仍尽力分析原始元数据。
- 静态归属地数据不是实时定位、身份核验或权属确认。
- SQLite 删除记录、carving、隐写等输出可能是启发式候选，应保留来源与限制并人工复核。
- 浏览器保存状态只是恢复便利，不替代原始检材保管；`.fppcase` 默认保留原始证据引用，不嵌入全部原始文件。
- 第三方组件与数据保留自身许可。手机号数据源固定修订的原始 LICENSE 文件为空，发行包明确保留来源说明，**不将其误标为 MIT/Apache 授权**。再分发者应先解决相应授权或替换数据源。
- 旧部署文档中的凭据已经从当前文档移除；历史副本仍应视为曝光，删除文字不等于轮换凭据。

## English summary

Forensics++ **1.0.0** is the first stable release of the browser-based forensics workbench. It ships clearer capture-detail/EXIF views, local HEIC/HEIF preview decoding, offline OpenCC Chinese conversion and a complete offline application ZIP.

Download **`ForensicsPP-v1.0.0-offline-static.zip`**, verify its SHA-256 and extract the complete folder. Use preinstalled Python 3 to run `python3 start_server.py`, then open `http://127.0.0.1:8765/`. The launcher installs nothing and binds only to loopback. Full Worker/WASM operation requires local HTTP; GitHub's source archives are not the ready-to-run package.

Runtime JavaScript, CSS, workers, WASM, CyberChef, dictionaries and lookup data are bundled. Fresh-cache offline browser checks completed with external traffic blocked and no external runtime requests in the tested flows. The candidate passed 501 tests across 94 files and the recorded desktop/mobile, loaded-state and package checks.

Review the tool-specific limits and the licensing notice for the existing phone dataset, whose pinned upstream LICENSE is empty. Third-party notices and HEIC corresponding sources are included. Previously exposed deployment credentials must be rotated by the owning operator even though they were removed from current documentation.
