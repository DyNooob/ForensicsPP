# Forensics++ v1.0.2 — 解压后直接打开的离线版

本版修正 v1.0.0 / v1.0.1 离线包的启动方式：现在完整解压后，直接用当前版本的 Chrome 或 Edge 打开 **`index.html`** 即可使用。地址栏为 `file://`。

**无需 Python、Node.js、命令行、本地 HTTP 服务、首次联网或预热缓存。**

## 下载与使用

1. 下载 **`ForensicsPP-v1.0.2-offline-static.zip`**，不要把 GitHub 自动生成的 Source code 当成运行包。
2. 用 `SHA256SUMS-v1.0.2.txt` 核对 ZIP 的 SHA-256，完整解压。
3. 双击文件夹中的 `index.html`。保留完整目录，包括 CyberChef 和许可证。

旧版离线包依赖本地 HTTP，已由本版替代。旧版本记录保留，便于核对已下载文件；推荐分发本版。

## 修正内容

- 分析线程改为自包含 Blob Worker，不再尝试从 `file://` 载入模块线程。
- SQLite、YARA 等 WASM 资源随运行代码提供。
- IP、手机号、行政区划数据库在构建时校验并嵌入，首次使用也可直接离线查询。
- PDF 分析所需的嵌套线程同样随包提供。
- 移除离线包中的 Python 和平台启动脚本，更新中英文使用说明。
- PNG 分析保持 v1.0.1 的已修复行为，本版不调整 PNG 恢复算法。

## 验证与范围

验证记录见 [本版检查说明](v1.0.2-audit.md)。重点是以 `file://` 运行真实分析，而非仅测试页面打开。离线 HTML 策略限制外部脚本、样式、数据及网络连接；外部网络型 CyberChef 操作不可用。

图像解码、工具大小上限和浏览器内存限制仍然适用。归属地数据库是固定版本记录，不代表实时定位。HEIC/HEIF 是尽力支持。

## 版权

ZIP 包含项目 MIT 许可证、第三方许可证、数据来源清单、CyberChef 版权信息和 HEIC 对应源码。第三方组件保留各自条款；手机号数据上游授权情况见随包说明及 `licenses/lookup/phone-UPSTREAM.txt`，不推定其已获 MIT/Apache 授权。

## English

Extract **`ForensicsPP-v1.0.2-offline-static.zip`** and open **`index.html`** in current Chrome or Edge. No Python, Node.js, terminal, local server, Internet connection or warm browser cache is needed. Keep the complete directory. This replaces the server-dependent offline packages from v1.0.0 and v1.0.1. Network-based CyberChef operations remain blocked by the offline policy. All bundled components retain their licenses.
