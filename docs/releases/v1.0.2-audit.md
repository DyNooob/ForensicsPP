# v1.0.2 离线发布检查

本版检查以直接打开 `file://…/index.html` 为交付条件，不以本地 HTTP 替代。

## 检查范围

- 项目类型检查、单元测试、文档链接和版权头。
- 完整解压包的版本、静态文件、数据 SHA-256、HEIC 对应源码和许可证。
- 全部可见工具初始化，以及三类查询、OpenCC、哈希线程、SQLite WASM、CyberChef、HEIC、PDF 和 YARA 的实际操作。
- 浏览器使用全新测试状态及封闭网络代理，不开启允许任意文件访问或禁用网页安全的参数。

已执行的浏览器检查：当前 Chrome，直接使用 `file://`，36 个工具初始化；三类冷启动查询、OpenCC 快捷键、哈希线程、SQLite/YARA WASM、PDF 元数据、CyberChef Base64、iPhone HEIC 预览均通过，外部运行资源请求为 0。独立的单页兼容检查 23 项通过；PNG 字节/像素恢复及移动布局回归通过。

完整 `npm run verify` 通过：98 个测试文件、545 项测试，包含新增 3 项离线构建契约测试；生产构建、类型、文档和翻译检查通过。交付检查要求独立解压最终 ZIP，再按同样的 `file://` 路径复验。浏览器实测范围为当前机器上的 Chrome，不声称已跨所有系统和浏览器测试。

## 已知限制

仅承诺记录过的浏览器与样例覆盖，不等于所有格式、编码和损坏情况均可处理。保留既有文件大小、内存和分析上限。浏览器扩展和操作系统网络活动不在 HTML 策略控制范围内。第三方数据授权边界见随包许可证与数据来源说明。
