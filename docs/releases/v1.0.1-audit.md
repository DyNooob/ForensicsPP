## 解释限制

- PNG 宽高搜索使用原 IHDR CRC 和扫描行约束；CRC 被覆盖后，多个布局可能同时成立，需人工复核。对照测试来自独立生成的 PNG 和逐像素比对，不声称与所有第三方恢复工具逐一交叉验证。
- PNG 宽高、像素数、解压和校验预算均有明确上限；未匹配不代表没有隐写。范围见结果解读文档与界面提示。
- 宏、外部引用、私有数据块、透明通道及高熵均不能单独证明恶意或隐写。
- 归属地静态数据随包固定，可能滞后于实时分配；手机数据许可说明、HEIC 许可/对应源码范围与 1.0.0 保持一致。
- GitHub Pages 的文件同步超时属于未完成部署，必须另行核对线上入口与资源；不将构建通过写成上线成功。
