# Forensics++ v1.0.1 — PNG 宽高恢复与清晰的检查结果

**修订正式版 · 2026-11-10 · 36 个工作台 · 简体中文 / English**

本次更新让图片异常、检查范围和下一步操作更容易理解，并补齐 PNG 宽高恢复。简繁转换成为左侧独立工具。1.0.0 既有发布附件保持原样，新版本使用新的 ZIP 与校验文件。

## 下载与启动

下载 `ForensicsPP-v1.0.1-offline-static.zip`，使用 `SHA256SUMS-v1.0.1.txt` 校验后完整解压。在解压目录运行：

```sh
python3 start_server.py
```

随后打开 `http://127.0.0.1:8765/`。Windows 可双击 `Start-ForensicsPP.bat`，macOS 可运行 `Start-ForensicsPP.command`。启动器使用本机 Python 3 标准库，无需 pip 或 npm 安装。已有本地静态 HTTP 服务也可使用。

离线 ZIP 包含运行所需 JS、CSS、Worker、WASM、CyberChef、OpenCC 词库、查询数据库、依赖许可证与 HEIC 对应源码。首次使用无需联网或预热缓存。完整 Worker / WASM 功能应通过本地 HTTP 打开，不能仅以 `file://` 双击 HTML。

## 主要变化

### PNG：恢复真实宽高，而不只是重算 CRC

- 联合原始 IHDR CRC 与完整 IDAT 过滤扫描行搜索尺寸，可处理宽、高或两者同时被修改的常见题目。
- 支持多段 IDAT、PNG 合法颜色类型与位深，以及 Adam7 交错图片。
- 使用 CRC 线性反解推导高度，避免完整二维枚举；搜索范围为宽高 `1–65535`、5000 万像素以内。
- 若原 CRC 也被覆盖，则展示扫描行候选并明确标注未确认，供用户比较预览；不会宣称唯一恢复。
- 恢复只改副本的宽高和 IHDR CRC，其余数据块、压缩像素、元数据与尾部字节保留。可下载、对照原图，或选择“分析此副本”继续像素分析。
- 异常大的文件头尺寸不再阻止容器检查；会跳过危险的像素分配，并将其标记为“声明尺寸（未验证）”。
- 修复自动扫描可能取消手动修复的任务竞争；较慢的修复任务仍可正常完成。

解压输出上限为 64 MiB，扫描行检查上限为 800 万次；最多展示 8 个尺寸候选，副本总大小另受 64 MiB 预算限制。IDAT 损坏、其他头字段损坏或范围外的尺寸可能无法恢复，界面会说明原因。单独重建关键块仍会明确说明其移除元数据等行为，并注明“不恢复宽高”。

### 结果：中文说明与一致分级

- 红色标记明确校验或操作失败，橙色标记待复核线索，绿色标记某项检查通过，蓝色提供说明，灰色标记尚未执行。
- 图片、二进制与 JWT 检查记录使用统一的提示组件，异常优先展示，保留原始偏移、协议字段和证据内容。
- 补齐文件头、数据块、解码、修复、签名等检查说明；未知解析器错误提供中文上下文，并保留原始技术信息以便排查。
- 磁盘、内存、固件、注册表、文档、流量与压缩包视图分别突出越界、限制、宏/动作/外部引用、捕获缺口和加密条目等情况。
- 不再把常规的大量元数据、普通文本块或透明像素直接当成异常。

### 图片工作台：从结论到操作

- 概览先显示结论与异常证据，再提供“结构与校验 → 宽高与容器修复 → 附加与隐藏内容 → 像素与位平面”四个固定入口。
- 默认结构视图直接显示已产生的检查记录；接通此前已计算但未展示的隐藏内容检查结果。
- CRC 表格以中文区分保存值与计算值，并突出失败项。
- 无法解码的占位说明改为中文，并提示仍可检查原始容器。已提取 EXIF 与完整元数据继续可见。

### 简繁转换：左侧独立入口

直接在左侧“转换”分类选择“简繁转换”，不再归入编码解码。内置 OpenCC 离线词库、地区字形与词汇、文件导入导出和快捷键保持可用。

- `Ctrl / ⌘ + Enter`：繁体转简体。
- `Ctrl / ⌘ + Shift + Enter`：简体转繁体。

### 部署可靠性

- 保留旧页面仍引用的哈希资源，避免部署切换后缓存页面引用不存在的 JS。
- 主站 HTML 和 Service Worker 采用及时更新的缓存规则；资源 CDN 仍只存运行资源，不上传 Release ZIP。
- 发布成功以线上页面与资源验证为准，不将构建完成或同步中视为上线完成。

## 验证与边界

具体验证范围见随包 [体检记录](v1.0.1-audit.md)。已完成的功能回归包括真实 PNG 的恢复字节、完整像素与原图一致性、超大声明尺寸、慢 Worker 的任务竞争、独立简繁入口、断网快捷转换和移动布局。
