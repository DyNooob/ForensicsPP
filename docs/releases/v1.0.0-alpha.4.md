# Forensics++ v1.0.0-alpha.4

## 中文

这一版继续收紧工具的工作区行为，重点是“算完以后还能继续用”。

### 主要变化

- 哈希页会保存明确计算完成的文本哈希和文件哈希结果。返回页面后仍可复制、筛选和导出；重新选择文件后才会开始新一轮计算。
- 字符串提取和熵值分析会保存完成的分析结果，刷新后仍可查看结果表。
- 大文件只保存受控大小的字节预览，不会把整份检材无限写入浏览器存储。恢复后可以继续查看结果和导出；查看原始字节上下文时重新选择源文件即可。
- 清理本地数据改为清空现有 IndexedDB 记录，避免多标签页场景下清理结果不可靠。
- 设置页兼容没有 `navigator.storage.estimate()` 的浏览器。
- 继续保持按需哈希：普通分析不会额外计算 SHA-256，邮件附件和 PCAP 提取文件也只有点击后才计算。

### 验证

- 85 个自动测试通过。
- TypeScript、版权头、生产构建、静态发布包和 36 个工具的桌面/窄屏布局审查通过。

## English

This release makes completed work easier to resume. The focus is on keeping useful results available without persisting original evidence indefinitely.

### Highlights

- The Hash tool now restores explicitly calculated text and file results. They remain available for copying, filtering, and export; selecting new files is required before another calculation.
- Strings and Entropy restore completed analysis results after switching tools or refreshing the page.
- Large-file workspaces keep only a bounded byte preview instead of persisting the full evidence item. Results and exports remain available; the original file is required again for byte-context inspection.
- Clearing local data now clears records in the existing IndexedDB store, which is reliable when another tab has the database open.
- Settings no longer assumes that `navigator.storage.estimate()` exists.
- Hashing remains deliberate: ordinary analysis does not calculate extra SHA-256 values, and email/PCAP extracted-file hashes are calculated only after an explicit action.

### Verification

- 85 automated tests passed.
- TypeScript, copyright headers, production build, static package verification, and desktop/narrow layout audits for all 36 tools passed.
