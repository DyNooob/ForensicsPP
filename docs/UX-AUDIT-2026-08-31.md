## 3. 发现的问题

### 3.1 双重首次启动门槛（中）

| 项目 | 内容 |
|------|------|
| 严重程度 | 中 |
| 区域 | 全局首页 / 首次加载 |
| 表现 | 用户首次进入需依次关闭“使用前确认”（法律免责声明）和“欢迎使用 Forensics++”（4 步新手指引）两个全屏弹窗，才能与工具目录交互。 |
| 影响 | 增加首次使用成本；连续两个弹窗可能让取证场景下的应急用户感到繁琐。 |
| 证据 | `clean-home.png`（新手指引覆盖在工具目录上）、`probe-home.png`（法律声明覆盖） |
| 状态 | 按设计实现；建议产品决策是否合并为一步或默认折叠新手指引。 |

### 3.2 移动端顶部栏分类+工具名换行挤压（低）

| 项目 | 内容 |
|------|------|
| 严重程度 | 低 |
| 区域 | 顶部栏 / 宽度 ≤ 390px |
| 表现 | 顶部区域把“分类 / 工具标题”折成两行，第二行只剩一两个字，显得局促且不直观。例如 390×844 下“分析 / 压缩包目录”第二行只显示“日”的部分。 |
| 影响 | 不影响功能，但降低移动端品牌/导航的清晰度。 |
| 证据 | `narrow-archive.png`、`narrow-hash.png` |
| 状态 | 未修复 |

### 3.3 证据收件箱切换工具后仍保持打开（低）

| 项目 | 内容 |
|------|------|
| 严重程度 | 低 |
| 区域 | 右侧抽屉 / 全局 |
| 表现 | 打开证据收件箱后，通过 hash 路由切换到其他工具时，抽屉不会自动关闭，会遮挡新工具的主区域。 |
| 影响 | 用户可能误以为工具页面空白，或需要手动关闭抽屉。 |
| 证据 | `documentforensics-clean.png`、`evtx-clean.png`（收件箱抽屉覆盖在工具上方） |
| 状态 | 可能为设计选择（保持全局访问），但建议考虑切换工具时自动收起。 |

### 3.4 Archive 预览面板内容需滚动才可见（低）

| 项目 | 内容 |
|------|------|
| 严重程度 | 低 |
| 区域 | 压缩包目录 → 预览面板 |
| 表现 | 选中条目并点击“加载预览”后，抽取出的文本内容显示在预览面板最底部，1440×900 下会被裁切，需要用户手动滚动右侧面板。 |
| 影响 | 用户可能误以为没有加载成功。 |
| 证据 | `archive-tar-extract.png`、`archive-zip-extract.png`（右侧面板底部 textarea 被裁切） |
| 状态 | 未修复 |

## 5. 排除的误报

| 误报 | 说明 |
|------|------|
| `#document` 渲染 AndroidManifest | 第一轮 `document.png` 实为无效 id（应为 `documentforensics`）。Phase 3 验证 `#document` 不渲染任何工具标题；截图显示 AndroidManifest 是 test artifact，已排除。 |
| Archive 条目抽取失败 | Phase 2 中“点击条目无内容”是因未点击“加载预览”按钮，仅完成了条目选择。Phase 3 正确点击后抽取成功。 |

## 6. 建议优先级

1. **中**：评估是否将“法律声明 + 新手指引”合并为单一首次弹窗，或在进入后通过更低调的方式展示指引。
2. **低**：移动端顶部栏在窄屏下采用单行省略或折叠分类名，避免标题被截成单字。
3. **低**：证据收件箱在切换路由时自动收起，或至少在新工具加载后让主区域重新获得焦点。
4. **低**：Archive 预览面板抽取完成后自动滚动到底部 textarea，或调整面板内部布局让内容可见。
